# Collaborative Course Creation Tool

A real-time, web-based platform that enables educators to collaboratively create, manage, and refine academic courses with structured content, inline comments, and role-based access.

## 💡 Key Features

- **Real-Time Editing**: Multiple users can co-edit content simultaneously.
- **Inline Commenting**: Threaded discussion for collaborative input.
- **Role-Based Dashboards**: Educators and students have tailored views.
- **Student Feedback**: Students can rate and comment on courses.
- **Content Management**: Support for multimedia uploads and structured modules.
- **Version Control**: Tracks and manages course revisions.

## 📁 TechStack

- **Frontend**: React, Tailwind CSS, TypeScript
- **Backend**: Supabase (PostgreSQL, Auth, Realtime)
- **Authentication**: Supabase Auth
- **Collaboration**: WebSockets
- **Testing Tools**: Postman, React Testing Library
- **Hosting**: GitHub

## ⚙️ Methodology

- Agile development with weekly sprints
- User-centered design with continuous feedback
- Role-based access control (RBAC) via Supabase policies
- Git-based version control for collaboration

## 📊 Outcomes

- Enhanced teamwork in course creation
- Reduced version control issues
- Improved student engagement through real-time feedback
